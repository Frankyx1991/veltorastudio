Cada juego y aplicación tiene sus propios enlaces legales. Aquí te explicamos el uso de la web de Veltora Studio.

La web del estudio

Esta web es informativa. No incorpora cuentas, compras, formularios para recoger datos, anuncios, herramientas de analítica ni cookies propias. Los recursos y tipografías se sirven desde el mismo sitio, sin proveedores externos de fuentes.

El alojamiento utiliza GitHub Pages. GitHub puede registrar información técnica, incluida la dirección IP, para proteger su servicio. Consulta su declaración de privacidad.

Si nos escribes

Los botones de contacto abren tu aplicación de correo. Tú decides si envías el mensaje. Utilizamos la dirección y el contenido que facilites para atender tu consulta. Evita enviar contraseñas, datos de pago u otra información innecesaria.

Responsable: Francisco Javier Ruiz Vidal, Veltora Studio, España. Contacto: soporte.veltorastudio@gmail.com.
